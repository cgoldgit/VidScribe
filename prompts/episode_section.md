# 多分P 合集的单集写作规范

一套多分P 课程（比如 100 集的《C语言程序设计》）先**逐集**写出一节正文，
再用 `src/merge_book.py` 把若干节合并成一本书。

通用规矩（课堂实录式轻度整理、按包写作、审阅记录、Mermaid、公式、时间锚点……）一律见 `stitcher_system.md`，
这份只讲不一样的地方。

## 你写的这一节，将来是书里的一节

合并时脚本会把你的标题**整体降一级**（`#` → `##`），所以：

- 本集标题用 `#`，节内小标题用 `##`，再细分用 `###`。别手动降级，脚本会做。
- **不要写书头信息块**。书的名字和导语由脚本生成，不属于任何一集。
  想自己写一段导语，就放到 `output/<书名目录>/_intro.md`，合并时会被放在最前面。

## 输入

- 字幕：`output/<BV号>_p<N>/transcript.json`（`duration` 是本集总秒数，
  `segments` 逐句，`start`/`end` 形如 `00:01:23`）
- 本集标题：看 `title` 字段末尾，形如 `p07 1.3.1 第一个C程序：如何在DevC++中编辑…_高清`，
  取 `p<N>` 之后、`_高清` 之前的那段课程小节号与标题

## 标题怎么写

用课程自己的小节号起头，后面可以接一个更口语的中文小标题：

```markdown
# 1.3.1 第一个C程序：如何在DevC++中编辑、编译和运行程序
```

顺手把上传者加的噪音去掉——`p07`、`_高清`、`720P` 这些不该出现在书里。

## 这一节的篇幅和配图

- **保留本节完整讲解链**：按原顺序写清原例子、每一步操作、遇到的错误、修正与结果。
  同一演示跨阅读包时接续完成，不按字数截短。每句去向记入 `note_review.json`。
- **按需求配图**：幻灯片、代码、编译报错、程序运行结果、流程图都先确认用途再核图。
  相同代码窗口的无关动作可以省略，新增代码、错误状态和结果不能因超过固定图数而删掉。
  格式、需求清单与核图方法见 `stitcher_system.md`。
- **大章节小结**：源稿每个实际 `##` 大章末写 **本章小结**，用 2—4 句概括结论、适用条件和易错点。
  本集结束时也写一次本集整体小结，供合并后 `#` 降为 `##` 的课程节使用；
  内部章节的小结随标题层级保留，不重复复述。跨阅读包只在真实章末或集末总结，不能替代详细讲解。
- **事实与广告处理**：按通用规范区分识别错误、知识错误、故意错误演示和有条件的意见。
  知识错误证实后写 **勘误** 并附证据，未证实写 **待核实**；保留报错到修复的教学链。
  省略无教学价值的广告、优惠和导流口播并记录原句去向，保留实际教学工具与操作。

## 代码忠于来源

这门课讲 C，代码需结合画面和上下文核对，再放进语言标注为 `c` 的代码块。
有明确证据时，`printf`、`scanf`、`sizeof`、`%d`、`&&`、`||`、`#include <stdio.h>`
按 C 的实际写法还原。原例子的错误代码若承担教学作用，先展示错误及反馈，再展示修正，
不要直接替换掉。片段仍保留为片段；实际执行或编译前不声称可运行。

## 术语表

下面是这门课的候选纠错表。结合语境确认后再改，不能机械替换：

| 字幕里可能出现 | 正确写法 |
|---|---|
| Dev C++ / DevC / dev c | DevC++ |
| print f / prince f | printf |
| scan f / scam f / scanf 函数 | scanf |
| 井号 include / 英克路得 | `#include` |
| 门函数 / 面函数 / man 函数 | `main()` 函数 |
| stdio 点 h | `<stdio.h>` |
| 百分号 d / 摆放 d | `%d` |
| 双精读 / 大伯 | double |
| 佛洛特 / float 型 | float |
| 卫语句 / well 语句 / 威尔语句 | while 语句 |
| 佛语句 | for 语句 |
| 萨维奇 / switch case | switch-case |
| 裤 / 库函数 | 库函数 |
| 数组 / 数主 | 数组 |
| 指针 / 真指针 | 指针 |
| 字符串 / 自负串 | 字符串 |
| 常量 / 长量 | 常量 |
| 编译 / 编意 | 编译 |
| 断点 / 单步调试 | 断点、单步调试 |
| PAT 系统 / pat | PAT（Programming Ability Test） |
| 一百分 / 百分号 | 按上下文判断是 `%` 还是 100 分 |

表里没有的同音错词，先核对前后文与画面；证据不足时保留原词并记录待核，不按常识猜事实。

> 整理的，别的课程用不上。
